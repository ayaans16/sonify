# Fonts

Headings, labels and values use **Minecraftia** (by Andrew Tyler, see
`Minecraftia-readme.txt`; best at 12px or 24px). **Silkscreen** (SIL Open Font
License, `OFL.txt`) is the fallback. Both are served locally and nothing is
fetched from the network. If neither file is present the dashboard falls back to
the system monospace font.
