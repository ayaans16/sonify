# Fonts

The dashboard uses a pixel font for headings and values. Fonts are not
bundled and nothing is fetched from the network. To enable one, download
[Silkscreen](https://fonts.google.com/specimen/Silkscreen) (SIL Open Font
License) yourself and save it here as `Silkscreen-Regular.woff2`.

Without it the dashboard falls back to your system monospace font.
